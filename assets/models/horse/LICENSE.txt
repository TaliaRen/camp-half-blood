Modifications made to produce this file (downloaded 2026-11-13)
---------------------------------------------------------------
Upstream ships the mesh and each clip as separate GLBs, the clips compressed with EXT_meshopt_compression.
This file is a lossless re-pack of those files into one plain GLB:
  * model.glb is used unchanged (mesh, skin, material, embedded palette texture);
  * each clip's keyframes were meshopt-decoded and attached to the model's own nodes (matched by node name),
    so no meshopt decoder is needed at runtime;
  * "Walk" and "Trot" got one closing keyframe (a copy of their first keyframe, one frame = 1/30 s after the
    last one) so that they loop without a pop. That closing frame is identical to the last frame of the same
    clips in upstream's mesh2motion-assets/rigs/horse/horse-animations.glb. Durations therefore read
    0.9667 s (Walk) and 0.7000 s (Trot) instead of upstream's 0.9333 s / 0.6667 s.
Nothing else was changed. sha256 of upstream model.glb: 7d783e721e611f3624bba5644907a7193c2c12266e328985ae1e4f5bab33af18
